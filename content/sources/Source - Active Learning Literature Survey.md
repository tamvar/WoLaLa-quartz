## Summary
Burr Settles surveys active learning as the problem of choosing which unlabeled instances should be annotated in order to learn efficiently with limited labeling budgets. For WoLaLa, the source matters because it gives a clean methodological map for annotation-efficient language research and evaluation design, especially where labels are expensive and query strategy shapes the evidence base.

## WoLaLa Relevance
This source primarily supports [[../overviews/Applications and Best Practices Overview|Applications and Best Practices]] and secondarily [[../overviews/Cultural, Cognitive, and SSH Perspectives Overview|Cultural, Cognitive, and SSH Perspectives]]. It is useful because it turns annotation choice into an explicit methodological variable. The survey distinguishes pool-based selection, stream-based selection, membership queries, uncertainty sampling, query-by-committee, expected error reduction, and related variants, which makes it a helpful background source whenever language-centered evaluation depends on scarce expert labels.

## Limitation Or Open Question
The survey predates the modern LLM era and is not specific to language tasks. The open question is which active-learning lessons transfer cleanly to current prompt-based evaluation, synthetic-data generation, and human-feedback pipelines.
